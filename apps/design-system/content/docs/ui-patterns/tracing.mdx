```tsx
import { Trace } from 'ui-patterns/Trace'
```

`Trace.Root` indexes a list of OpenTelemetry-style spans and shares the result with the parts inside it. `Trace.Waterfall` is the layout container and measures its width so time can be mapped to pixels. `Trace.Ruler` draws the time axis.

## Waterfall and Ruler

The ruler adapts its ticks to the visible range. While a trace is live (any span has no end), it also draws a line at `nowMs`. Pass `nowMs` on the trace to pin it, and `minRangeMs` to keep a minimum visible duration while live.

## Minimap and zoom

`Trace.Minimap` compresses the whole trace into a full-width strip above the ruler, with one row per depth level, colored by span status. The brush shows the visible window. Drag the brush to pan, drag either edge to resize it, or click outside the brush to recenter it. With the brush focused, the left and right arrow keys pan, and Shift with an arrow key moves the end edge.

Until the window is changed, it follows the trace as it grows. Once it is zoomed it stays fixed, and ruler labels still read as offsets from the trace start. Read and control the window with `useView()`: `window`, `setWindow(start, end)` and `resetWindow()`.

## Rows and bars

`Trace.Rows` is a virtualized, scrollable list with one row per visible span. Its children are the row template and render once per row. `Trace.Cell` is the tree column: indent by depth, an expand and collapse toggle, the span name, and `Trace.Duration`, which pulses while the span is running. `Trace.Lane` is the timeline column, a positioned container for the primitives below.

Four primitives go inside a `Trace.Lane`. `Trace.Bar` draws the span from its start to its end, tinted by status. A running span extends to `nowMs`. `Trace.Markers` places a marker at each of the span's event timestamps. `Trace.CollapsedChildren` draws a tick at each direct child's midpoint when a span is collapsed. `Trace.Slowest` badges the longest finished span. Compose them in this order so markers and the badge draw over the bar:

```tsx
<Trace.Lane>
  <Trace.Bar />
  <Trace.CollapsedChildren />
  <Trace.Markers />
  <Trace.Slowest />
</Trace.Lane>
```

Rows follow the tree pattern. Use the arrow keys to move between rows, Right and Left to expand and collapse (Left on a collapsed row moves to its parent), and Enter or Space to select. Read the selection and collapse state with `useView()`.
